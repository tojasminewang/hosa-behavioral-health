## Memory basics
- **Memory:** the ability to keep knowledge
- **Information processing continuum:** processing flows bottom-up and top-down across sensation, attention, perception, learning, memory, thinking, problem solving
- Memory works in three steps: encoding, storage, retrieval
- **Encoding:** taking in information and moving it into memory
- **Storage:** keeping information in the brain
- **Retrieval:** getting stored information back
- Adaptive advantage: using the past to meet challenges quickly

## Processing memories
- **Atkinson-Shiffrin model:** information passes through stages; anything not passed on is lost for good; sensory input → sensory memory → short-term memory (kept alive by rehearsal) → long-term memory, with forgetting out of the first two stages
- **Sensory memory:** lots of incoming information for a very short time; separate channels for each sense (sound, sight, etc.)
- **Short-term memory (STM):** a little information for a limited time; about 5–9 bits for at most about 30 seconds; chunking stretches how much it holds, rehearsal how long
- **Rehearsal:** repeating information
- **Chunking:** grouping similar or meaningful pieces
- **Long-term memory:** home of permanent memories; very large capacity, very long duration

![The Atkinson–Shiffrin model](hc-memory-model)

- **Levels of processing theory:** deeper processing (shallow to deep) predicts easier retrieval
- **Working memory:** extension of STM: actively handling several kinds of information at once; Alan Baddeley's model (Baddeley and Hitch, 1974): unlike STM, which only stores passively, it lets us work on information and juggle several types at once

| Part of working memory | Job |
|---|---|
| Phonological loop | Verbal and auditory (sound) information |
| Visuospatial sketch pad | Visual and spatial information |
| Central executive | Directs attention to tasks, managing the other parts |
| Episodic buffer | Combines information stored in long-term memory |

![The four parts of working memory](hc-working-memory)

- **Primacy effect:** better recall of the first list items, thought to be in long-term memory
- **Recency effect:** better recall of the last list items, thought to still be in working memory at recall

![Primacy and recency effects (a sketch)](hc-serial-position)

## Long-term memory
- **Declarative (explicit) memory:** conscious, easy to put into words; semantic, episodic, autobiographical
- **Semantic memory:** general knowledge (what a churro is); organized by category
- **Episodic memory:** personal experiences (a beach vacation); personal history, organized by time
- **Autobiographical memory:** semantic or episodic memories about yourself
- **Nondeclarative (implicit) memory:** unconscious, effortless, hard to put into words: classical conditioning, procedural learning, priming
- **Procedural memory:** implicit memory for skilled movements; hard to put into words but easy to demonstrate; automatic skills
- **Priming:** a changed response to a stimulus after exposure to an earlier one

![Types of long-term memory](hc-ltm-types)

- The hippocampus consolidates information into long-term memory
- **Patient H.M.:** surgery damaged his hippocampus; procedural memory intact, but no new declarative memories
- **Anterograde amnesia:** inability to form new memories, as in H.M.
- Semantic, episodic, autobiographical memories involve the cerebral cortex; procedural memories, the basal ganglia
- **Spreading activation model:** connectionist theory: people organize general knowledge from their own experiences; concepts linked more or less strongly
- **Schema:** expectations about objects and situations

## Retrieval and forgetting
- Sternberg: we search STM one item at a time, not all at once
- **Cue:** stimulus that aids retrieval; topics under cues: recognition vs recall, self-generated cues, encoding specificity, context-dependent memory
- Recall gives fewer cues than recognition, so recall is harder
- **Encoding specificity:** memories hold a unique mix of information from encoding
- Retrieval isn't all-or-none (tip-of-the-tongue phenomenon); it comes gradually, and a wrong retrieval can block the right one or act as a cue for it
- **Reconstruction:** rebuilding a memory from stored pieces; newer memories are more open to it, which matters for eyewitness testimony; fuzzy trace theory and source monitoring belong here too
- **Fuzzy trace theory:** limited resources go to different memories by need: verbatim (exact) to gist (general idea)
- **Flashbulb memory:** vivid, detailed memory of an emotional event; may form when stress and learning coincide; with emotion, timing matters, and chronic stress affects memory too
- **Forgetting:** reduced ability to remember something once stored
- **Decay:** rarely used information becomes harder to retrieve over time
- **Interference:** newer and older information compete
- **Proactive interference:** earlier learning blocks the target memory
- **Retroactive interference:** later learning blocks the target memory

![Two kinds of interference](hc-interference)

- **Motivated forgetting:** failing to retrieve negative memories

## Biology and study tips
- **Long-term potentiation (LTP):** stronger communication between two neurons from activating them together
- Axon terminals increase after sensitization, decrease after habituation
- Acetylcholine (ACh) affects memory, especially encoding new information
- **NMDA receptor:** a glutamate receptor (N-methyl-D-aspartate), prime candidate for learning changes like LTP
- **Distributed practice:** studying spread over time instead of massed practice (cramming)
- **Testing:** practising retrieval with tests
- **Interleaving:** mixing topics and skills within a session instead of one topic at a time
- **Exercise:** improves neurogenesis in mice; helps health and mood
- **Sleep:** helps form memories and fights interference
- **Reciting:** putting material in your own words
- **Mnemonics:** aids linking new information to well-known information
